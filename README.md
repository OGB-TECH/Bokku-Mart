# Bokku Mart Website

## About the Project

Bokku Mart is a public-facing website
project inspired by the official Bokku website.

The project is built using HTML, CSS,
and Vanilla JavaScript.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Visual Studio Code

## Website Pages

1. Home
2. About Us
3. Work With Us
4. Partner With Us
5. Locations
6. Contact Us

## Project Folder Structure

```text
BOKKU-MART/
├── html/
├── css/
├── js/
├── assets/
└── README.md
```

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the `html/home/index.html` file.
3. Run the file using Live Server.

## Project Features

- Responsive website layout.
- Navigation between pages.
- Contact form.
- Reusable header and footer.
